## 注意

- `slidekit_overflow*.png` は研修スライド（第7回）の画面。社内の発表なので問題ないが、社外に出す場合は確認すること。
- 画面下のバーには `/Users/shirotabi/...` のローカルパスが写っている。気になる場合は撮り直すか、Googleスライド側でトリミングする。
- 「サムネイル一覧」（Gキー）の画面は撮れていない。必要なら、slidekit で `G` を押して手動で撮る。
- 「はみ出し12枚」は、第7回に未コミットの変更がある状態で撮影した数値（22枚中12枚）。
