# 高校生のための直線と距離による座標補正

## これは何をする話？

画面にある点を、好きな場所へ動かせるとは限らない。たとえばゲームのキャラクターが道路の上しか歩けない、部品がレールの上しか動けない、という状況を考える。

ここでは、次の問題を考える。

1. 点 `P` は、自分専用のレール（直線）の上しか移動できない
2. 目印になる基準線が、別の場所へ動いた
3. 点はレールの上を動いて、基準線からの距離をできるだけ元と同じにしたい

点が基準線の右側から左側へ移ることは許す。大切なのは「どちら側か」ではなく、**何だけ離れているか**だ。

```text
前:  点 P は基準線から 5 離れている
後:  点 Q も新しい基準線から 5 離れていれば成功
```

## 1. 座標は地図の番地

平面上の場所を `(x, y)` で表す。`x` は右へ行くほど大きく、`y` は上へ行くほど大きいものとする。

```text
          y
          ↑
          |       P=(3, 4)
          |        ●
          |
──────────+────────────→ x
          |
```

`P=(3,4)` は「右に 3、上に 4」の場所だ。プログラムでは次のように持てる。

```cpp
struct Point {
    double x;
    double y;
};
```

## 2. 直線を、縦線も困らない形で書く

学校で習う直線の式は `y = ax + b` が多い。この形は斜め線や横線には便利だが、縦線 `x = 2` を書こうとすると、傾き `a` が決められず困る。

そこでコンピュータでは、次の形が便利だ。

```text
Ax + By + C = 0
```

この式なら、どの向きの直線も書ける。

| 直線 | 一般形 `Ax + By + C = 0` |
|---|---|
| 横線 `y = 3` | `0x + 1y - 3 = 0` |
| 縦線 `x = 2` | `1x + 0y - 2 = 0` |
| 斜め線 `y = -3x` | `3x + 1y + 0 = 0` |

`A` と `B` が両方 0 だと、直線にならない。そこだけは入力ミスとして弾く。

## 3. 点から直線までの「最短距離」

点から直線までの距離は、斜めに測るのではない。一番短い、直角に下ろした線の長さを使う。

```text
       P ●
         |  ← 直線と直角
         |  距離 d
─────────┼──────── 基準線
```

直線が `Ax + By + C = 0`、点が `(x, y)` のとき、距離 `d` は次の式だ。

```text
             |Ax + By + C|
d = ─────────────────────────
           √(A² + B²)
```

縦棒 `| |` は絶対値で、「マイナスならプラスに直す」という意味だ。だから、基準線の上側にいても下側にいても距離は正になる。

### 例: 横線からの距離

基準線を `y = 2`、点を `P=(5,7)` とする。

```text
y = 2 は 0x + 1y - 2 = 0
A=0, B=1, C=-2

          |0×5 + 1×7 - 2|     |5|
d = ───────────────────── = ─── = 5
            √(0² + 1²)         1
```

たしかに `y=7` から `y=2` までは 5 だけ離れている。

## 4. 「距離が 5 の場所」は 2 本の平行線

基準線から距離がちょうど 5 の点を全部集めると、基準線の両側に 1 本ずつ、合計 2 本の平行線になる。

```text
距離 5 の場所    ─────────────────────

基準線            ═════════════════════

距離 5 の場所    ─────────────────────
```

これは「基準線から 5 離れた場所を探す」問題を、「2 本の線のどちらかに乗る場所を探す」問題へ変えるコツだ。

元の点 `P` と元の基準線の距離を `d0` とすると、新しい基準線から同じ距離 `d0` の場所は、必ずこの 2 本になる。

## 5. レールとの交点が答えになる

点には自分だけのレールがあるとしよう。点はレールから外れられない。

新しい基準線から距離 `d0` の 2 本の線と、レールを交わらせる。

```text
距離 d0 の線     ─────────────────────
                          /
                         /  レール
                        ●  候補 A
                       /
新しい基準線       ═════/════════════════
                     ● 候補 B
                    /
距離 d0 の線     ─────────────────────
```

候補 A と候補 B は、どちらも新しい基準線からの距離が `d0` である。つまり、元の「基準線からの離れ具合」を完全に再現している。

この方法は、レールを少しずつ動いて距離を何度も測る方法より確実だ。探す候補が最初から最大 2 個に決まるからである。

## 6. 候補が 2 個なら、より少ししか動かない方

両側の候補が見つかったときは、どちらも距離の条件を満たしている。そこで次は、元の点 `P` から近い方を選ぶ。

2 点 `(x1,y1)` と `(x2,y2)` の距離は、三平方の定理から求められる。

```text
移動距離 = √((x2 - x1)² + (y2 - y1)²)
```

平方根 `√` は、比べるだけなら省略できる。`√` は 0 以上では大きさの順番を変えないため、次の値が小さい方を選べばよい。

```text
(x2 - x1)² + (y2 - y1)²
```

```text
優先順位
1. 新しい基準線との距離が元と同じか（誤差が最小か）
2. 同じなら、元の点からの移動距離が短いか
```

## 7. 元の点が基準線の上にあるとき

元の点が元の基準線の上にあれば、元の距離は `d0=0` だ。

```text
P ●──────────── 元の基準線
  距離 0
```

新しい基準線から距離 0 の場所は、新しい基準線そのものになる。したがって答えは単純で、**レールと新しい基準線の交点**だ。

## 8. レールと基準線が平行なら？

レールが新しい基準線と平行なとき、レール上をどれだけ進んでも基準線までの距離は変わらない。

```text
レール             ─────────────────────

新しい基準線       ═════════════════════
```

このとき、元の距離 `d0` と今の距離が同じなら、レール上のどこにいても距離の条件は満たせる。元の点のままなら移動距離が 0 なので、元の点を選べばよい。

距離が違うなら、レール上のどこへ動いても改善できない。やはり誤差はどこでも同じなので、「一番少なく動く」という約束に従い、元の点を返すのが自然だ。

## 9. コンピュータの小数には、少しだけあいまいさがある

コンピュータの小数は、`1/3` のような数を完全には保存できない。そのため、本当は同じはずの値が

```text
5.0000000000
4.9999999998
```

のように少しずれることがある。

そこでプログラムでは `a == b` と完全一致を調べる代わりに、差が十分小さいかを調べる。

```cpp
constexpr double epsilon = 1e-9;
bool almostEqual(double a, double b) {
    return std::abs(a - b) <= epsilon;
}
```

また、ほぼ平行な 2 直線の交点を計算すると、とても大きな座標になることがある。分母が小さすぎるときは無理に割り算をせず、「平行として扱う」安全策が必要だ。

## 10. まとめ

この問題のコツは、「距離が同じ場所」を直接探し回らないことだ。

1. 元の点と元の基準線の距離 `d0` を測る
2. 新しい基準線から距離 `d0` の平行線を 2 本作る
3. 各点のレールとの交点を求める
4. 交点が 2 個なら、元の点から近い方を選ぶ
5. 平行なら距離は変わらないので、元の点を選ぶ

この計算を点ごとに独立して繰り返せばよい。点の数が増えても、点同士を比べたり、全体を一度に最適化したりする必要はない。

```text
「全員の並び方」を直す問題ではない
「一人ずつ、自分のレール上で元の距離を守る」問題である
```
