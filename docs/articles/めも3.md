今のコードはこういう処理です。

srcの高さをそのまま保ったまま、

つまり、

src 200行
↓

でも、適用側が渡されたテーブルを使うだけで、内部で imageY >> 1 などをしているなら、画像上ではこう見えます。

dst上の200行
↓
画像上では400行分、またはそれ以上に効く可能性がある

なので、変換側でどうにかするなら、srcをdstへ置くときにY方向を伸縮させる処理を追加するのが候補です。

⸻

まず今のコードの意味

今のコードは「等倍コピー」です。

const int dstY = dstStartY + srcY;
dstRow[x] = srcRow[x];

これは、

src row 0   → dst row dstStartY
src row 1   → dst row dstStartY + 1
src row 199 → dst row dstStartY + 199

です。

つまり、srcの1行をdstの1行として扱う。

この処理自体はきれいです。
ただし、適用側がY方向に別スケールを持っているなら、画像上の効き方は変わります。

⸻

選択肢は主に2つです。

⸻

案1：今のまま等倍コピーする

これは現状です。

srcHeight行をdstHeight内にそのまま置く

メリット：

データを壊しにくい
単純

デメリット：

適用側のYスケールによって、画像上の高さが変わる

今の問題はここです。

⸻

案2：Y方向だけリスケールしてから左下配置する

今回やるなら、これが一番現実的です。

↓

↓

という考え方です。

今の関数に、こういう引数を足すのがいいです。

int dstCopyHeight

意味は、

です。

例えば、

srcHeight = 200

という使い方です。

Y方向リスケール版コード

今回は、まず最近傍で十分です。
補正テーブルなので、いきなりバイリニアを入れるより、まずは「行対応が合うか」を見る方が優先です。

#include <cstdint>
#include <algorithm>
using U16 = std::uint16_t;
/*
    小さいシェーディング補正テーブルを、
    大きいシェーディング補正テーブルの左下に配置する。
    ただし、Y方向だけ dstCopyHeight 行にリスケールして配置する。
    例:
        srcHeight = 200
        dstCopyHeight = 200  → 等倍
        dstCopyHeight = 100  → 縦方向を1/2に圧縮
        dstCopyHeight = 50   → 縦方向を1/4に圧縮
    注意:
        X方向はそのままコピーする。
        今回は「幅は合っていて、高さだけズレる」ため。
*/
bool replaceShadingTableLeftBottomU16_ScaleYNearest(
    const U16* src,
    int srcWidth,
    int srcHeight,
    int srcLineSpanBytes,
    U16* dst,
    int dstWidth,
    int dstHeight,
    int dstLineSpanBytes,
    U16 noCorrectionValue,
    int dstCopyHeight
)
{
    if (src == nullptr || dst == nullptr)
    {
        return false;
    }
    if (srcWidth <= 0 || srcHeight <= 0)
    {
        return false;
    }
    if (dstWidth <= 0 || dstHeight <= 0)
    {
        return false;
    }
    if (srcWidth > dstWidth)
    {
        return false;
    }
    if (dstCopyHeight <= 0 || dstCopyHeight > dstHeight)
    {
        return false;
    }
    if (srcLineSpanBytes % static_cast<int>(sizeof(U16)) != 0)
    {
        return false;
    }
    if (dstLineSpanBytes % static_cast<int>(sizeof(U16)) != 0)
    {
        return false;
    }
    const int srcLineSpanElements =
        srcLineSpanBytes / static_cast<int>(sizeof(U16));
    const int dstLineSpanElements =
        dstLineSpanBytes / static_cast<int>(sizeof(U16));
    // ------------------------------------------------------------
    // 1. dst全体を補正なし値で初期化する
    //
    // 0で埋めると、余白が黒くなる可能性がある。
    // ------------------------------------------------------------
    for (int y = 0; y < dstHeight; ++y)
    {
        U16* dstRow =
            dst + y * dstLineSpanElements;
        for (int x = 0; x < dstWidth; ++x)
        {
            dstRow[x] = noCorrectionValue;
        }
    }
    // ------------------------------------------------------------
    // 2. 左下配置の開始Y
    //
    // 今回はsrcHeightではなく、リスケール後のdstCopyHeightを使う。
    // ------------------------------------------------------------
    const int dstStartY =
        dstHeight - dstCopyHeight;
    // ------------------------------------------------------------
    // 3. srcをY方向にリスケールしながらdstへコピーする
    //
    // dst側の1行が、src側のどの行に対応するかを逆算する。
    //
    // 例:
    //   srcHeight = 200
    //   dstCopyHeight = 100
    //
    //   dst側100行に対して、src側200行を割り当てる。
    //   つまり、srcの2行ぶんをdstの1行に代表させる。
    // ------------------------------------------------------------
    for (int dstLocalY = 0; dstLocalY < dstCopyHeight; ++dstLocalY)
    {
        // dstLocalY を srcY に対応させる
        //
        // 最近傍:
        //   srcY = dstLocalY * srcHeight / dstCopyHeight
        //
        // dstCopyHeightがsrcHeightより小さい場合は圧縮、
        // 大きい場合は拡大になる。
        int srcY =
            dstLocalY * srcHeight / dstCopyHeight;
        if (srcY < 0)
        {
            srcY = 0;
        }
        if (srcY >= srcHeight)
        {
            srcY = srcHeight - 1;
        }
        const int dstY =
            dstStartY + dstLocalY;
        const U16* srcRow =
            src + srcY * srcLineSpanElements;
        U16* dstRow =
            dst + dstY * dstLineSpanElements;
        // X方向はそのまま
        for (int x = 0; x < srcWidth; ++x)
        {
            dstRow[x] = srcRow[x];
        }
    }
    return true;
}
