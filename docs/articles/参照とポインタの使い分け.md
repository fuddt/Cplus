# C++ 参照とポインタの完全整理

C++において `&` や `*` は複数の意味を持ち、初心者にとって最大の難所の一つです。このドキュメントでは、メモリ上の挙動から設計哲学までを整理します。

## 第1章：`&` 記号の3つの意味
混乱の最大の原因は、同じ `&` が文脈によって意味を変えることです。

1.  **参照型宣言（Reference）**: `int& r = x;`
    *   「`r` は `x` の別名（エイリアス）」であると定義します。
2.  **アドレス演算子（Address-of）**: `int* p = &x;`
    *   変数 `x` が置かれている「メモリ上の住所」を取得します。
3.  **右辺値参照（R-value Reference）**: `int&& r = 5;`
    *   一時的な値（右辺値）を効率的に扱うための高度な機能（初期学習時は無視してOK）。

## 第2章：参照とポインタの構造的違い
「別名」か「変数」か、という点が本質的な違いです。

| 項目 | 参照 (`T&`) | ポインタ (`T*`) |
| :--- | :--- | :--- |
| **実体** | 変数の「別名」そのもの | アドレス（住所）を格納する「変数」 |
| **初期化** | **必須**（宣言と同時に紐付けが必要） | 任意（`nullptr` を持てる） |
| **Null可能性** | **不可**（必ず何かを指している） | **可能**（何も指さない状態を作れる） |
| **再束縛** | **不可**（一生同じ変数の別名） | **可能**（途中で指す先を変えられる） |

### 「再束縛ができない」とはどういうことか？
ここが最も間違いやすいポイントです。

```cpp
int a = 10;
int b = 20;
int& r = a; // r は a の別名になる

r = b;      // これは「r の指す先を b に変える」のではない！
            // 「r（つまり a）に、b の値（20）を代入する」という意味。
            // 結果：a は 20 になり、r は相変わらず a を指している。
```

ポインタの場合、`p = &b;` と書けば、`p` が指す対象を `a` から `b` へ自由に切り替え（再束縛）られます。

## 第3章：設計意図の使い分け（なぜポインタが必要か）
「参照の方が安全なのに、なぜポインタを使うのか？」という問いに対する回答です。

### 1. 参照を使うべき場面： 「絶対にある」ことの保証
*   **関数の引数**: `void print(const std::string& s)`
    *   「文字列が必ず存在し、コピーせず中身だけ見たい」という意思表示です。
*   **安全性の確保**: Nullチェックが不要になり、バグが減ります。

### 2. ポインタを使うべき場面： 「状態」と「動的な構造」
*   **「空（無し）」を表現したい**: 検索の結果、見つからなかった場合に `nullptr` を返せます。
*   **指す対象を切り替えたい（状態の保持）**:
    *   例えば「現在選択されているアイテム」を保持する変数などは、ユーザーの操作に応じて指す先（アドレス）を変える必要があるため、ポインタが必須です。
*   **複雑なデータ構造**: 連結リストや木構造のように、ノードが次々と繋がっていく構造はアドレスによる結合（ポインタ）なしには実現できません。

## 第4章：関数の引数設計ガイド
実務で関数を定義する際、どの型を選ぶべきかの判断基準です。

1.  **`T` (値渡し)**:
    *   コピーを作って所有したいとき。または `int` などの非常に小さい型のとき。
2.  **`const T&` (定数参照渡し)**:
    *   **基本はこれ。** 重いオブジェクトを「読み取り専用で借りたい」とき。
3.  **`T&` (参照渡し)**:
    *   呼び出し元の変数を直接書き換えたいとき。
4.  **`T*` (ポインタ渡し)**:
    *   引数に `nullptr` を渡すことを許容したいとき。

## 理解度チェック（これが解ければ合格）

以下のコードを実行した後の、各変数の値を答えてみてください。

```cpp
int a = 10;
int b = 20;

int* p = &a;  // ① p は a を指す
*p = 50;      // ② p の指す先（a）を 50 にする
p = &b;       // ③ p の指す先を b に変える
*p = 100;     // ④ p の指す先（b）を 100 にする

int& r = a;   // ⑤ r は a の別名
r = b;        // ⑥ r（a）に b の値を代入する
```

**正解:**
*   `a`: **100** (②で50になり、⑥でその時のbの値100が代入された)
*   `b`: **100** (④で書き換えられた)

> **ポイント**: ⑥の時点で `b` は既に100になっているため、`r`（つまり `a`）には100が代入されます。参照 `r` が途中で `b` を指すように切り替わることは絶対にありません。
